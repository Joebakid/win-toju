# Win-Toju System Enterprise Limited — Corporate Web Platform

A high-performance, modern corporate web application built for **Win-Toju System Enterprise Limited** (RC: 1744024). The platform showcases the company's engineering expertise, marine logistics capabilities, waste management solutions, statutory regulatory compliance, and official documentation portal.

---

## 🚀 Tech Stack

* **Framework:** [Next.js](https://nextjs.org/) (App Router, Server & Client Components)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/)
* **Icons:** [React Icons](https://react-icons.github.io/react-icons/)
* **Language:** TypeScript / JavaScript

---

## ✨ Key Features

* **Interactive Hero Section:** Direct modal-based document preview highlighting statutory operational permits.
* **Corporate Resource & Compliance Center:** Interactive document viewer supporting direct PDF previews for all CAC certificates, Tax Clearance Certificates (TCC), NUPRC Specialized Permits, NIMASA registrations, and NCDMB certifications.
* **Dedicated Policy Pages:** Comprehensive legal compliance routes including Terms & Conditions, Privacy Policy, Anti-Bribery & Corruption Policy, Environmental Safety Policy, and Nigerian Content Directives.
* **Integrated Google Maps & Routing:** Headquarters locator embedded with direct contact mapping and multi-departmental inquiry handling (spanning procurement, engineering, job/internship applications, and vendor registrations).
* **Fully Responsive Design:** Optimized for mobile, tablet, and desktop viewports with a polished corporate Navy and Red aesthetic.
